# yume

Music beyond reality.

Aplicativo de música para Android, com reprodução offline, playlists e biblioteca.

## Compilação

Os APKs são compilados e assinados pelo GitHub Actions (aba Actions, fluxo "Build APK", botão Run workflow) e publicados na aba Releases.

A chave de assinatura fica apenas nos Secrets do GitHub e nunca é versionada.
